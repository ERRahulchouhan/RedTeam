# DeepTeam Experiment Guide

## What this folder is for

This folder contains a cell-by-cell set of safe, fictional scenario-evaluation examples. The notebook does **not** execute DeepTeam, call a model, or perform a live assessment.

## Methods in `experiment.ipynb`

1. Risk-category coverage
2. Scenario-based refusal test
3. Synthetic privacy scenario
4. Agent permission scenario
5. Multi-turn scenario
6. Evaluator rubric
7. Scenario regression
8. Groundedness scenario
9. Structured-result scenario
10. Scenario-set consistency

Each method explains the scenario, goal, and expected outcome. Run the Python cell immediately after its explanation to check the fictional fixture.

## Interview explanation

> “I organize an AI red-team assessment around risk categories and realistic, controlled scenarios. I define expected behavior, capture evidence, and retest after changes. This notebook shows a safe scenario-based structure; it does not claim that DeepTeam was run.”

## Safe-use note

Use only authorized systems and synthetic fixtures. Check the current DeepTeam documentation before wiring scenarios to a real target.
